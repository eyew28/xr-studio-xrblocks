Quest & Virtual Desktop Setup

Enabling WebXR on PC Chrome

1
Check Virtual Desktop OpenXR Runtime:

In the Virtual Desktop Streamer window on your PC, open Settings and verify that OpenXR runtime is set to Virtual Desktop (or SteamVR).

2
Check PC Chrome WebXR Flag:

In Chrome on your PC, navigate to chrome://flags, search for WebXR, and ensure WebXR Device API is set to Enabled.

3
Native Quest Browser Option:

You can also open this development URL directly in the native Meta Quest Browser on your Quest headset for zero-setup 1-click VR!
